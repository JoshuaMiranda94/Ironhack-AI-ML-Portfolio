# Ironhack AI & Machine Learning Portfolio

Selected coursework and technical exercises completed during the Ironhack AI & Machine Learning program.

This repository is a **curated portfolio**, not a dump of every lab completed during the program. The goal is to show the strongest areas of hands-on work in data analysis, machine learning, deep learning, NLP, LLM applications and generative AI.

The original course repositories included instructions, starter notebooks and exercise scaffolding provided by Ironhack. This curated repository is intended to present my own learning, implementation decisions and technical takeaways in a cleaner format.

Course materials remain attributed to Ironhack. The portfolio summaries here are written as a professional overview of the work I completed.
